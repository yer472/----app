# 学习笔记（XXBJ）

按「科目 → 章节 → 笔记」三级结构记录课堂笔记的本地应用。纯前端、无后端，数据全部存在本机浏览器的 IndexedDB 里。

完整的产品设计见 [XXBJ.md](XXBJ.md)。

## 快速开始

```bash
npm install
npm run dev      # 开发服务器，浏览器打开提示的地址
npm run build    # 类型检查 + 打包到 dist/（同时生成 dist/sw.js）
npm run serve    # 起本地服务器，http://127.0.0.1:24816/
npm run lint     # oxlint
npm run icons    # 从 public/icon.svg 重新生成图标（改了图标才需要跑）
npm run verify:pwa   # 端到端验证离线能力（需要先 build）
npm run verify:board # 端到端验证绘图功能（自己起 dev 服务器，不用先 build）
npm run verify:shortcuts # 端到端验证键盘快捷键（自己起 dev 服务器，不用先 build）
```

**浏览器要求：Chrome 或 Edge。** Firefox / Safari 对 File System Access API 支持不全，自动备份功能会不可用。

## 日常使用

**地址是 `http://127.0.0.1:24816/`，这个地址不要改。** 它同时决定了四件事：笔记存在哪、离线缓存存在哪、装出来的桌面应用是哪一个、任务栏上那个图标是谁。换一个端口不会迁移任何东西——你会看到一个空的应用、任务栏上多出来的第二个图标，而笔记还留在旧端口下。

第一次装：

```bash
npm run build
npm run serve
```

然后在 Edge 里打开 `http://127.0.0.1:24816/`，点地址栏右侧的「安装」图标（一个带加号的显示器）。装完会有自己的任务栏图标，`Alt+Tab` 能切过去。

**装完之后就不需要开着服务器了。** Service Worker 把整个应用（约 3.5MB，148 个文件）缓存了下来，双击图标直接打开，服务器关着也行。实测过：关掉浏览器、服务器全程没启动、重新打开，应用正常。

只有两种情况需要再跑一次 `npm run serve`：

- **改了代码要更新。** 重新 `npm run build`，起一次服务器，在设置页点「立即更新」。
- **离线缓存被清掉了**（比如手动清理了浏览器数据）。应用会打不开，跑一次服务器打开一次就恢复了，笔记数据不受影响。

## 编辑器

基于 **Milkdown Crepe**——存储的是纯 Markdown，编辑时即时渲染（敲 `## ` 当场变成标题，符号自动隐藏）。输入 `/` 会弹出插入菜单。

**图片**：直接 `Ctrl+V` 粘贴截图、或者把图片文件拖进编辑区。图片会自动压缩到长边 1600px 以内再存进 IndexedDB，正文里留一个 `asset://<附件id>` 引用。

格式策略是**跟着输入走**：截图（PNG）仍然存 PNG，照片（JPEG）仍然存 JPEG。不一律转 JPEG 是因为文字截图用 JPEG 会出现振铃状的糊边，而且 PNG 对这类内容往往体积更小、还能保住透明区域。

**自动保存**：停止输入 1 秒后落盘，标题和正文用同一套机制。离开页面、切换笔记时都会兜底保存一次，不会丢内容。

## 绘图

笔记页右上角的「插入图形」按钮打开画板。目前有直线、矩形、椭圆、手绘四种工具，网格吸附（`▦` 按钮切换），撤销重做（`Ctrl+Z` / `Ctrl+Shift+Z`，深度 50 步），选择工具下可拖动、`Delete` 删除。工具快捷键是 `V`/`L`/`R`/`O`/`P`（完整的按键清单见「键盘快捷键」一节）。

画完点「完成」，图会插到正文的**光标位置**。再次点「插入图形」可以列出本篇笔记已有的图，点「编辑」接着改。

**存的是一张自带数据的 SVG。** 可见的图元负责显示，场景数据（每个图元的类型和坐标）内嵌在 SVG 的 `<metadata>` 里负责「下次还能接着改」。这样一个文件既是渲染结果又是源数据，正文里只需要一行普通的 Markdown 图片引用，于是备份、孤儿清理、导入导出、离线缓存全部沿用既有管线，一行都不用改。

编辑已有的图时是**覆盖同一个附件**，正文里的引用保持稳定；覆盖之后会主动刷新页面上那张 `<img>`，否则你会看到「数据库里明明是新的、屏幕上还是旧的」。

**两个要知道的取舍：**

- **图形颜色不跟随主题。** 正文里的图是 `<img src="blob:...">`，SVG 在 `img` 里是独立文档，**继承不到页面的 CSS**。所以按制图惯例固定成白底黑线——浅色主题下完全正确，深色主题下是一张「白图纸」。
- **图形不进搜索。** 场景数据在附件里，而且搜索会先把正文转成纯文本（图片整段丢掉），所以搜「四杆机构」搜不到那张图。

**这个功能不做的事：** 不做运动学仿真，不做参数化求解。图是结构化的、能重新打开编辑，但改一个杆长不会让整个机构自动重算位置——那需要约束求解器。也不做完整的 GB/T 4460 线型规范。详见 [XXBJ.md](XXBJ.md) 的 §1.4。

验证方式是 `npm run verify:board`，13 项断言。它跑的几条都是「看起来能跑但其实是坏的」那类故障：SVG 渲染成空白却不抛异常、`![说明](url)` 里的说明文字被静默吞掉、覆盖附件后正文里还是旧图、附件类型在备份往返中悄悄降级。脚本会自己起一个 dev 服务器（端口 5199），跑完自动清理自检数据。

## 搜索

侧栏的搜索框（或 `Ctrl+K`）跳到搜索页，跨全部科目检索标题和正文。结果里命中处会高亮，并显示所属科目 / 章节，可以按科目收窄范围。

匹配前会先把正文转成**纯文本**，不是直接匹配 Markdown 原文——否则搜 `asset` 会命中每一张图、搜 `##` 会命中每一个标题，结果里全是噪声。

实现是内存里的全表扫描（`SearchRepository`）。几百篇笔记是几毫秒级；到设计文档说的「1000 篇 / 1 秒」那个量级，需要给正文加一份归一化的小写文本字段并建索引。现在不提前做，是因为真正的瓶颈要等有真实数据才知道在哪。

## 键盘快捷键

**完整的清单在设置页里**（「设置与备份」→ 键盘快捷键），按 `Ctrl+/` 可以直接跳过去并高亮那一节。清单分四组，每组都标了生效范围——因为这四组的实现者根本不是同一个：

| 分组 | 说明 |
| --- | --- |
| 全局 | 任何页面都生效 |
| 页面 | 跟着当前所在页面变 |
| 编辑器 | **由编辑器（Milkdown Crepe）自带，不是本 App 实现的**。光标在正文里时它们优先于全局快捷键 |
| 绘图 | 只在画板打开时生效 |

除了清单里有的，`Ctrl+F` 是**故意不接管**的——留给浏览器原生的页内查找（在一篇长笔记里找一句话时有用），全局找东西走 `Ctrl+K`。

### 两条支撑整个设计的机制

**1. 全局层靠 `event.defaultPrevented` 给编辑器让位。** 所以 `Ctrl+B` 在正文编辑器里是**加粗**、在别处才是折叠侧栏——同一个键在不同焦点下做不同的事，而且不需要维护「焦点在不在编辑器里」这种判断。ProseMirror 命中按键时会 `preventDefault()`（`node_modules/prosemirror-view/dist/index.js`），它的监听器在 `window` 的上游，所以能看见。代码块里的 CodeMirror、输入法的组合状态也走同一条路。

**2. 对话框或画板开着时，全局快捷键整体让位。** 靠的是一个模块级的浮层计数（`lib/shortcuts/overlay.ts`），不是查 DOM——画板没有 `role="dialog"`，按属性查恰好会漏掉最需要挡的那个（里面有未保存的图）。少了这一条，在「新建科目」里填了一半再按 `Ctrl+K` 会被导航走，连输入框一起卸载。

**组合键只写在 `lib/shortcuts/catalog.ts` 里一处**，绑定代码只引用条目 id。所以清单里写的和按下去生效的在数据上就是同一份，不可能对不上——自检脚本还会双向比对「目录里写了没绑」和「绑了目录里没写」。

`Ctrl+N` / `Ctrl+T` / `Ctrl+W` 这类**浏览器保留键**一律不用：页面根本收不到，绑了等于没绑。自检脚本里有一条专门守着这个。

验证方式是 `npm run verify:shortcuts`，29 项断言、端口 5198。它跑的几条都是「看起来能跑但其实是坏的」：对话框开着时快捷键还在生效、`Ctrl+B` 被侧栏抢走导致没法加粗、笔记→笔记切换把上一篇的正文写进下一篇、画板里 `Shift+R` 也切工具、浮层计数只加不减导致所有全局键永久失效、目录和绑定对不上。

## 数据安全与备份

**这是本项目最重要的一组功能。** 笔记存在浏览器的 IndexedDB 里，站点数据被清理就会全部丢失。设计文档 §7.4 定了三层防护，入口在侧栏「设置与备份」：

| 层级 | 实现 |
| --- | --- |
| 第 1 层 | 启动时请求持久化存储权限（`navigator.storage.persist()`）。浏览器可能不批，设置页会如实显示状态 |
| 第 2 层 | 自动备份到用户选的文件夹：镜像（`data.json` + `笔记/科目/章节/标题.md` + `images/`）+ 每日快照 zip（保留 7 天） |
| 第 3 层 | 设置页的「导出为 zip 文件」 |

导出格式是**开放**的：`笔记/` 里的 `.md` 用记事本、VS Code、Obsidian 都能直接打开，图片是 `images/` 下的普通文件，不依赖本 App。详细说明见 [XXBJ.md](XXBJ.md) 的 §7.4 和 M3 实施记录。

### 数据库自检

开发服务器跑起来后访问 `/dev/db-check`，可以一键验证 IndexedDB 的读写与级联删除是否正常。它会创建临时数据并在结束时清理干净，不会污染真实笔记。等功能稳定后这个页面可以删掉。

## 离线与安装

**为什么能脱开服务器**：`scripts/build-sw.mjs` 在每次构建后扫一遍 `dist/`，把所有资源写进 `dist/sw.js` 的预缓存清单，清单内容的哈希当缓存名。Service Worker 装好之后，导航请求由它直接用缓存的 `/index.html` 应答，客户端路由交给 React Router 解析。

几个不显然的设计决定：

- **预缓存跳过 `.woff` 和 `.ttf`。** 每个 KaTeX 的 `@font-face` 都把 `woff2` 列在 `src` 的第一位，而 Edge 支持 woff2，后面两个格式永远不会被请求。这一条省掉 40 个文件约 798KB。
- **`install` 里不调 `skipWaiting()`，`activate` 里不调 `clients.claim()`。** 如果调了：你开着应用的时候重新构建，新 SW 会立刻接管并删掉旧缓存，而运行中的页面内存里还是旧模块图，它懒加载 `NotePage` 时请求的是新哈希文件——那些文件已经不在磁盘上，路由会静默挂掉。延迟之后，旧页面继续用旧缓存服务，你点「更新」才切换。
- **代价是：因为导航走缓存优先，普通刷新永远拿不到新版本。「立即更新」是唯一的更新入口。** 所以这个提示必须显眼：有新版本时，**应用底部会出现一条横幅**，点上面的「立即更新」即可（设置页的「应用与离线」里也有同样一个按钮）。光是重新打开应用就会自动检测到新版本，不需要手动去点「检查更新」。

  > 这条横幅是吃过亏才加的。加完绘图功能之后，应用里装着的是旧版本、界面上找不到新按钮，而唯一能发现新版本的入口藏在设置页深处——不会有人没事去翻设置页。既然「更新」是唯一的路，提示就不能只待在一个角落。
- **`fetch` 里先判断协议再判断 origin。** `blob:` URL 的 origin 就是页面自己的 origin，只判 origin 会把笔记里的图片请求也拦下来，而 CacheStorage 只接受 http(s)，缓存操作会直接抛。
- **资源请求失败时绝不回退到 `index.html`。** 模块脚本收到 HTML 会报 `Unexpected token '<'`，把「文件缺失」伪装成语法错误。

验证方式是 `npm run verify:pwa`，22 项断言，包括「清空 HTTP 缓存后断网仍能打开」和「关掉浏览器重开、服务器全程没启动仍能打开」。

### 为什么自己写服务器而不用 `vite preview`

两个原因。一是端口必须固定且**绝不自动切换**——`serve.mjs` 遇到端口被占用会直接报错退出，因为静默换端口会让你的笔记「消失」（它们还在旧端口下）。二是 `vite preview` 对任何 404 都回 `index.html`，于是一个缺失的分片会返回 HTML，浏览器报 `Unexpected token '<'`，把「文件没了」伪装成语法错误。`serve.mjs` 的 SPA 回退只对不带扩展名的路径生效。

## 注意事项

- **备份权限按会话过期。** 重新打开 App 后需要点一下「重新授权」——这是浏览器的安全模型，绕不过去。
- **备份文件夹里的 `笔记/` 和 `images/` 只增不删。** 在 App 里删掉一篇笔记，文件夹里对应的 `.md` 不会被清理。这样做是为了绝不误删用户文件；恢复以 `data.json` 为准，残留文件不影响结果。
- **IndexedDB 按浏览器 + 用户配置隔离。** 换浏览器或换用户配置打开，看到的是空的。装成桌面应用之后请固定用它作为入口。
- **应用图标在安装时就被 Chromium 快照下来了。** 之后改 `public/icon.svg` 不会更新任务栏图标，需要卸载重装（卸载不会删数据）。
- **装完之后设置页的「浏览器占用」会涨约 3.5MB**，那是离线缓存。不是泄漏。
- **自动备份只在 App 开着的时候跑。**
- **侧栏折叠之后怎么展开：按 `Ctrl+B`，或者点左边那条窄栏上的 `»`。** 折叠时侧栏是**整个卸载**的，没有别的入口——这条窄栏按钮是专门为此加的。
- **`Alt+N` 需要人工确认一次。** 自动化测试测不到输入法：中文输入法正在选字时浏览器把按键报成 `'Process'`，快捷键会静默不生效。10 秒自检：微软拼音切到中文 → 敲 `nihao` 让候选窗弹出来 → 按 `Alt+N`（**没反应是正常的**，输入法在选字）→ 按 `Esc` 关掉候选窗 → 再按 `Alt+N`，**这一下必须有反应**。如果仍然没反应，说明这个组合在中文环境下不可用，换成 `Ctrl+Alt+N` 并同步改 `catalog.ts` 和 `XXBJ.md`。
- **`Ctrl+S` 需要人工确认一次**：按下去应该**不弹** Edge 自己的「保存网页」对话框（靠 `preventDefault` 压掉）。注意编辑器把正文交给保存层有最多 200ms 的延迟（见 `XXBJ.md` 的 M4 实施记录），所以刚敲完立刻按可能漏掉最后一两个字，随后那次自动保存会补齐，不会丢数据。
